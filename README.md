This is my fork of [rust-mpd](https://github.com/kstep/rust-mpd) which
I use in my MPD client, [inori](https://github.com/eshrh/inori). It adds a small and simple tokio
interface available through the `async` feature. It also includes some
minor correctness fixes and spec-compliant connection fallback order.
